# Techloom.ai Email Footer

HTML email signature footer for Techloom.ai.

## Files

- `email.html` — Copy this into your email client signature (Outlook, Gmail, etc.)

## Preview

Open `email.html` in a browser to preview the layout.

## Usage

1. Open `email.html` in a browser.
2. Select all and copy.
3. Paste into your email signature settings (use HTML/rich text mode where supported).
