# Techloom.ai Email Footer

HTML email signature footer for [Techloom.ai](https://www.techloom.ai).

**Repository:** [github.com/Thaksigan23/email_footer](https://github.com/Thaksigan23/email_footer)

**Preview:** [thaksigan23.github.io/email_footer/preview.html](https://thaksigan23.github.io/email_footer/preview.html) (after GitHub Pages deploys)

## Files

- `email.html` — Copy into your email signature (Gmail, Outlook, Apple Mail)
- `preview.html` — Open in a browser to preview

## Usage

1. Open `email.html` in a browser (or use `preview.html`).
2. Select the footer table and copy.
3. Paste into your email client signature settings (HTML / rich text mode).

## Notes

- Icons use one family: white [Icons8](https://icons8.com/) iOS Glyphs inside solid black circles (like your reference sheet).
- For Outlook, if the logo does not show, replace the SVG logo URL with a PNG hosted on your site.
